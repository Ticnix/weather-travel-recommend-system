## 与主流天气产品的差异

墨迹/彩云/苹果天气卖"天气信息"，本产品卖"**天气 × 用户的行程与偏好**"：

- 别人只会报"明天有雨"，这里会扫到用户明天上午有白云山的行程并**主动推送**改期建议；
- 排行程时坏天气自动只排室内（与行程页同一套打分规则，不会自相矛盾）；
- 说一次"怕晒、带老人"，之后每轮对话、排程、推荐都遵循。

**成本模型是第二差异**：除 LLM 对话外全部零 API 成本——
海报 canvas 纯排版、穿搭/提醒规则模板、语音转写本地推理、逐小时/AQI 免费源。
