# 0004 · 基础设施端口只绑 127.0.0.1

日期：2026-09-29 ｜ 状态：已采纳（部署前检查发现）

## 背景

docker-compose 里 Postgres `5432` / Redis `6379` / 后端 `8000` / Mailhog
`1025,8025` 全部绑 `0.0.0.0`。公网部署时 **Redis 无密码裸奔**等同于开门
（可写键、可 RCE），Postgres 直接暴露暴力破解面，Mailhog 泄露全部测试邮件。

## 决策

以上端口一律改绑 `127.0.0.1`（本地开发不受影响，localhost 访问不变）；
仅 `8080`（用户端）、`8081`（管理端）保留对外，由 nginx 统一入口。

## 伴随要求

- 部署机 `.env` 的 `JWT_SECRET` 必须换新随机值（`change-me` 默认值在代码里可见）；
- 部署后立即改 admin 密码（`init_db.py` 播种 `admin / Admin@123456`，
  默认口令在公开仓库里可见）；
- Mailhog 是测试邮件服务，生产配置真实 SMTP 或不启动该服务。
