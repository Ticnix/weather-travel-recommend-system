# 0003 · 行程海报用 canvas 纯排版，不用 AI 生图

日期：2026-09-24 ｜ 状态：已采纳

## 背景

"晒行程"需求成立，但 AI 生图按张计费（此前因此被移除，见工作日志第十二节），
且行程/时间/地点属于**精确印刷类内容**——生成模型会把数字和汉字画错。

## 决策

前端 canvas 纯排版：手绘标题/日期跨度/按天分组清单/品牌落款，
devicePixelRatio 2x 导出 PNG。分享链路：Web Share API（仅触屏设备，
`pointer: coarse` 判定——桌面 Windows 的系统分享面板没有文件目标，是空的）
→ 不支持时下载 PNG → 用户取消（AbortError）静默。

## 后果

- 零 API 成本、断网可用、内容 100% 准确；
- 纯排版的信息密度反而高于生成图；
- 代价：版式能力受限于 canvas（对"行程清单"这种结构化内容无所谓）。
