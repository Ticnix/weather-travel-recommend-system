# 行程天气提醒指南

## 日期解析规则

| 表达 | 解析 |
|------|------|
| 今天/今日 | 当天 |
| 明天/明日 | +1 天 |
| 后天 | +2 天 |
| 大后天 | +3 天 |
| YYYY-MM-DD | 具体日期 |
| M月D日 | 当年该日期（已过则推到明年） |

## 提醒生成原则

针对每条行程，结合当天天气生成提醒：
- 雨天：提醒带伞/穿防滑鞋/户外活动是否改期
- 高温：提醒防晒补水/避开正午时段
- 大风：提醒保暖/户外注意安全
- 低温：提醒加衣保暖

## 数据隔离

- 行程检索强制 `WHERE user_id = :user_id`，多租户隔离
- 匿名用户（无 user_id）无法访问任何行程
