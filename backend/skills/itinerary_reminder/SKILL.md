# 行程天气提醒 Skill

## 何时使用
- 用户问"明天有什么安排""后天要注意什么""我的行程当天天气如何"等。

## 工作流程
1. 解析用户问题中的日期（今天/明天/后天/大后天/具体日期）
2. 按日期取出该用户的结构化行程（按时间排序）
3. 查询当天真实天气（从 7 天预报匹配日期）
4. 拼装"行程清单 + 当天天气 + 提醒指令"，交给 LLM 生成逐条提醒

## 关键设计
- 行程用结构化字段存储（date/start_time/location/activity），保证天气精确匹配
- 与用户私有知识库（纯文本分块）分离，因天气匹配需要精确字段
- 通过 contextvars 透传 user_id，实现多租户数据隔离

## 数据来源
- 行程：itineraries 表（结构化，user_id 隔离）
- 天气：统一天气服务层
