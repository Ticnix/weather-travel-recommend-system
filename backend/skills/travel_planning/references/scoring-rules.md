# 出行规划评分规则

## 评分公式

```
总分 = 0.4 × 时间分 + 0.3 × 费用分 + 0.3 × 天气分
```

三个分项均归一化到 0~1，分值越高越推荐。

## 时间分（0~1）

```
时间分 = max(0, 1 - 该方案耗时 / 所有方案最大耗时)
```

- 耗时越短分越高
- 用"相对所有方案的最大耗时"做归一化，避免量纲影响

## 费用分（0~1）

```
费用分 = max(0, 1 - 该方案费用 / 所有方案最大费用)
```

- 费用越低分越高

## 天气分（0~1）

从 1.0 开始扣分：

1. **降水惩罚**：`天气分 -= min(0.5, 降水mm / 20)`（每 20mm 降水扣 0.5）
2. **温度惩罚**（偏离舒适区 18~26°C）：
   - 平均温度 <10 或 >30：扣 0.3
   - 平均温度在 18~26 之外：扣 0.15
3. **恶劣天气关键词惩罚**：描述含"雨/雪/雷/雹/雾/霾/沙尘"任一，扣 0.2

## 交通方式合理距离区间

| 方式 | 合理距离上限 | 说明 |
|------|------------|------|
| 步行 | 3 km | 超过则剔除 |
| 骑行 | 15 km | 超过则剔除 |
| 驾车 | 不限 | 适合长距离 |
| 地铁/公交 | 不限 | 适合中长距离 |
