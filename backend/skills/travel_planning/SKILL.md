# 出行规划 Skill

## 何时使用
- 用户问"从X到Y怎么走""去X坐地铁还是打车""多久能到""多少钱"等路线/交通问题。

## 工作流程
1. 地理编码：把起终点地址解析为经纬度（高德 API，无 Key 时用内置地标/城市坐标兜底）
2. 路线规划：获取多套方案（驾车 + 地铁/公交，高德 direction API）
3. 天气查询：拉取当天天气用于评分与提示
4. 三维评分：时间(0.4) + 费用(0.3) + 天气(0.3)，归一化后加权排序
5. 输出多套方案，附天气提示

## 评分权重
| 维度 | 权重 | 说明 |
|------|------|------|
| 时间 | 0.4 | 耗时越短分越高 |
| 费用 | 0.3 | 费用越低分越高 |
| 天气 | 0.3 | 天气适宜度（降水/温度/恶劣天气惩罚） |

详见 `references/scoring-rules.md`。

## 数据来源
- 路线：高德地图 Web 服务 API（地理编码 + 驾车/公交路线规划）
- 天气：统一天气服务层（和风/Open-Meteo，可切换）

## 兜底策略
- 高德 Key 缺失或调用失败时，用内置广州地标坐标 + Haversine 球面距离 + 经验系数估算，保证链路可用。
