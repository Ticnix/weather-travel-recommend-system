# 活动场景穿搭规则

| 场景 | 功能性建议 |
|------|-----------|
| 爬山 | 防滑运动鞋/登山鞋 + 速干透气衣物，备防晒和轻便雨衣，护膝可选 |
| 逛街 | 舒适平底鞋/运动鞋 + 轻便衣物，背包方便购物 |
| 夜游 | 备一件薄外套（夜间降温），亮色或反光元素提高安全性 |
| 商务 | 正式衬衫/西装，深色为主，注意平整挺括 |
| 通勤 | 舒适鞋 + 易打理衣物，可叠穿应对室内外温差 |
| 露营 | 速干衣 + 冲锋衣，备保暖层和防潮垫，夜间需加厚 |
| 骑行 | 紧身速干衣 + 防风外套，头盔手套，反光装备 |
| 观景 | 防风外套 + 舒适鞋，高处风大注意保暖 |
| 亲子 | 轻便耐脏衣物 + 舒适鞋，备儿童替换衣物 |
| 摄影 | 深色耐脏衣物 + 舒适鞋，方便蹲起，备防雨罩 |
